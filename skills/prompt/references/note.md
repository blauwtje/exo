# Note

`Before it runs:`, then 1-3 numbered one-line items, most material first; none admitted → no note.

- Choice → 2-3 lettered options in fixed order, best marked: `1. Features: a) keep all (best) b) may change`. Free value → say what to give.
- Then the line `Reply ok to run as is, or answers like 1a or 2: <value>.`; in-session prompt → `Ok to run it?` follows.
- Admit one only when the user alone can supply it and it could change the work materially; each kind that fires:
  - Paid job → money cap.
  - Change of unclear size → how big (improve, remove, rewrite; features stay or not).
  - Named skill whose description rules out the task → keep it in the prompt; quote the clause.
  - Two readings leading to materially different work → name both.
  - Named path, file, symbol or skill step 2 did not find → check the name; not for one the prompt creates.
- Suggested item → never a value in the block; the reply supplies it.
- Not an item: what `## Add` puts in the block, a report of the rewrite, wording polish, anything the block answers, one shown earlier.
