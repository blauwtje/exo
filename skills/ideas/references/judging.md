# Judging

The judge reads `existing` and only the `## Ideas` sections of `ideas-a` and `ideas-b`, and writes only `judge`.

## Each idea

- **Verdict:** `exists`, `variant` or `new`, against What already exists.
- **Where it breaks:** the first place it fails.
- **Scores**, 0 to 5 each, total out of 20: Novelty, Usefulness, Feasibility, Survival.

## Then

1. Search the web once for each idea at 12 or more, and update its verdict.
2. Rewrite each idea at 12 to 15 once, and score it again.
3. Compare each idea at 16 or more with the Best existing answer twice, once in each order, because one order favours an option.

An idea is **strong** only when it scores 16 of 20 or more, its verdict is not `exists`, and it beats the best existing answer in both orders.

## The file

Rank strong ideas first. Give each of the top 3 a first test with `Pass if`, `Fail if` and `Cost`. Write the top 3, a table of every idea, one section per idea, and the line `Strong: <n> of <m>`. Reply with the top 3 and the path.
