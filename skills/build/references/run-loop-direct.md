In a wave, a failed sibling never discards a green task. That reference's step 4 saves each worktree's diff, then removes it. Any other line hands its report path, unread, to a repair delegate: `PLAN DRIFT` to `../drift-repairer-prompt.md`, `BLOCKED` or a failed `Run:` with no cause to `../bug-fixer-prompt.md`, a second failure stops the run `BLOCKED` with both reports and 2-3 options. A land-task refusal but `PLAN DRIFT` goes there, reruns once; a second stops likewise.
