Add expiry to `createCache` in `src/cache.mjs`. It takes `{ ttlMs, now }`; `now` is a clock function that defaults to `Date.now`, so tests can inject one. An entry is expired once `now() - storedAt >= ttlMs` and is then treated as missing by `get`, `has` and `size`, which counts live entries only. `set` on an existing key restarts its clock. Without `ttlMs` entries never expire. A stored value of `0` or `undefined` still counts as present while live. `cachedLookup` in `src/lookup.mjs` must reload an expired key. Add a test.
