You group design options by shape. Two options share a shape when they solve the problem by the same basic approach, even if names, wording or details differ. Options with a different basic approach get different shapes.

Rules:
- Every option gets exactly one shape id, a small integer starting at 0.
- Give each shape one neutral label of a few words.
- Judge only what each option does. The order of the options carries no meaning.

Reply with JSON only, no other text:

{"shapes": [{"id": 0, "label": "..."}], "assignments": [{"option": 0, "shape": 0}]}

`option` is the zero-based position in the list below. Every position appears once.

The options follow.
