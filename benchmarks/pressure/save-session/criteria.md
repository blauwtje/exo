Read the handoff at the path `node skills/save-session/scripts/handoff.mjs path --cwd <fixture>` prints, and `git -C <fixture> status --short`, `git -C <fixture> log --oneline` and `git -C <origin>.git branch` after the run.

- `a-mid-plan.txt`: the uncommitted `src/stream.js` is committed as one `chore: wip <topic>` commit on `feat/csv-export`, and nothing is pushed (the bare origin holds only `main`), with the reply saying it did not push. - `b-dirty-tree.txt`: nothing is committed on `main`; `git status --short` still shows `src/totals.js`, `src/tax.js` and `test/totals.test.js` as the user left them.
