# Agent effort: which agents keep their pass rate at a lower effort

This file scores Task 19 of `docs/specs/simpler-cheaper-exo.md`. The spec's decision: each agent drops to `medium` (`locate-code` and `fetch-docs` try `low`) and keeps the lower level only where its pressure cells show no loss.

- Only agents above the target level were candidates: `build-task`, `build-ui`, `critique-ui`, `fix-review`, `review-branch`, `survey-ui` and `solve-hard` (all `high`, target `medium`), and `fetch-docs` (`medium`, target `low`). `run-unit` already sits at `medium`. `locate-code` sets no effort (kind `lookup`, Haiku at the session's level).
- Only `build-task` and `review-branch` have pressure cases that dispatch the agent itself (`benchmarks/pressure/build-task/`, `benchmarks/pressure/review-branch/`). No case dispatches any of the other agents, so they have no cells that could show a loss or no loss.
- Each tested agent ran its kind's cell from `--cells-for`, `sonnet:high`, once per arm. `--setup` pointed at a wrapper named `<agent>/setup.sh` that archives the last run's fixture, then runs the case's own `setup.sh`, so every arm could be graded:

```
node skills/edit-skills/scripts/pressure.mjs --prompt benchmarks/pressure/<agent>/<case>.txt --cells sonnet:high --plugin-dir <copy with the agent at medium> --main-dir . --setup <wrapper>/<agent>/setup.sh
```

- The `main` arm loads this checkout at afbf2568, with the agent at `high`. The `with` arm loads a copy of the same commit with only that agent's `effort:` set to `medium`.
- Two earlier attempts at e5a0a728 blocked in both arms, since the runner kept the fixture read-only. be633a8c fixed that, and the scored runs below come after it.
- Verdicts: `lowered` when every case passes at the lower effort as it does at the current one; `unchanged` when a case loses a pass, the result is ambiguous, or no case exercises the agent.
- No run printed a `WRONG COPY` or `[unopened citation]` line. Total reported cost across all three attempts: $1.37.
