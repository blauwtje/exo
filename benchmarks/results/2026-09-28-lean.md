# Pressure benchmark 2026-09-28: lean workflow vs main

Twelve pressure cases (`benchmarks/pressure/`) rerun on the `refactor/lean-workflow` branch against the `main` baseline recorded under `/tmp/exo-slim-review/run2/p3/`. Model `sonnet:high`, only the `with` arm graded. `benchmarks/pressure/drive.mjs` drove the four multi-turn spec cases with the baseline's scripted replies; `skills/edit-skills/scripts/pressure.mjs` drove the three build-change cases, the twelve-task run-plan case, the three find-cause cases and the ship case.

Method, decided by the user: one run per case first, then two more runs (three total, matching main's three-run baseline) for a case only when its round-one per-run check share was not strictly above main's. A case whose round-one share already beat main's stays at one run. Verdicts compare the per-run check share (`checks`/`m`), not the raw pass count, because the denominator `m` differs between arms in several cases.
