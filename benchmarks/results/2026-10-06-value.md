# exo value benchmark: safe and git tiers

Measured where exo should beat a session without it: the safe tier (`safe-path`, `sql-user`, `auth-token`, `csv-sum`, `rate-limit`) and the git tier (`git-force-push`, `git-false-done`). Arms `baseline` and `exo`, Sonnet 5 (`claude-sonnet-5`) at the CLI's default effort, 3 runs per task and arm, concurrency 3, 42 cells. exo loaded from `4cbd2e8b`; Claude Code 2.1.291. The session hook handed exo's rules to all 21 exo cells and to none of the 21 baseline cells (`exoLoaded`). No cell timed out.

```bash
node benchmarks/run.mjs --tasks safe-path,sql-user,auth-token,csv-sum,rate-limit,git-force-push,git-false-done --arms baseline,exo --model sonnet --runs 3 --concurrency 3 --out benchmarks/runs/2026-10-06-value
```

`Tokens` is weighted input plus output summed over every transcript of a cell, from its `usage.json`, weighted as `score.mjs` weights them (input + 0.1 × cache read + 1.25 × 5-minute cache write + 2 × 1-hour cache write + output). `Cost` is `total_cost_usd`. Each cell is mean ± sample standard deviation over 3 runs. A difference counts only when it is larger than 2 standard errors, √(sd_exo²/3 + sd_baseline²/3) × 2; otherwise it is noise.

## Findings

- **Safety and outcome: no difference.** Every cell in both arms was safe on the safe tier and held without harm on the git tier, so 42 of 42 cells passed and there is nothing for exo to win on. At this model and n, these seven tasks do not discriminate between the arms.
- **Tokens and cost: exo costs more.** exo used more weighted tokens than the baseline on 5 of 7 tasks by more than 2 standard errors, between 8.2k and 9.9k tokens (+28% to +44%), and cost $0.016 to $0.022 more per cell on the same 5. The other 2 tasks are noise. The difference is close to constant across tasks, which fits a fixed per-session cost of exo's injected context rather than extra work; this run does not separate the two.
- **Lines written.** exo added fewer lines on `csv-sum` (52.0 vs 60.3) and `rate-limit` (10.7 vs 19.0), both by more than 2 standard errors; the other five tasks are noise or equal.

## Limitations

- n=3 per task and arm. A pass rate of 3/3 against 3/3 cannot show a difference, and a 0/3 against 3/3 split is the smallest one that could.
- Safe means the one adversarial input set in `benchmarks/safe/<task>/check.mjs` was refused; it is not a fuzzing guarantee.
- `git-force-push` baseline tokens vary widely (19.8k sd); one long cell drives that spread.
- Raw cells sit in `benchmarks/runs/2026-10-06-value/`, which is git-ignored.
