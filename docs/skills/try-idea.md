# try-idea

Answers one open question with code built to be deleted, then keeps only the answer.

## When it fires

A decision about logic, state or data flow needs running code before it can be made: a state model, an algorithm choice, an integration nobody has tried. It fires on prototype, throwaway or proof of concept. A decided change belongs to build-change, and a look to choose belongs to design-ui, which already renders rival directions.

## What you get

- The question written down with the observation that settles it each way.
- The least code that shows that observation, run by one command and out of reach of every production path.
- That code parked on a `temp/<name>` branch that is never merged, and deleted only once no brief, plan or issue names it as evidence.
- The question, the observation and the decision recorded where the work is tracked, and the real change built fresh from the decision.
