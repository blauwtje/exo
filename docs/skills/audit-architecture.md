# audit-architecture

Answers where the architecture should improve, when no exact change has been named.

## When it fires

You ask about tech debt, coupling, shallow modules or refactor candidates across a codebase or a subsystem without naming one change. A single named refactor, a failing behavior, or a security or dependency audit belongs elsewhere.

## What you get

- Ranked findings, each with what implementing it would take.
- Inside a read-only planning mode, the plan for the top findings as well, as the task list define-scope defines, ready for run-plan.
- A question offering define-scope, which turns the top finding into a confirmed brief.
