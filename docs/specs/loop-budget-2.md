# loop-budget-2

## Goal
Part 2 of loop-budget: only the main session waits on agents at depth 1, `wait-report.mjs` and the task-runner layer are gone, every remaining wait runs on the loop budget, and every worktree lives in `.claude/worktrees/<name>` of the main checkout; `npm run check` fails a script that brings any of them back. Part 1 (`docs/specs/loop-budget.md`, Tasks 1 to 12) is landed on main.

## Verdict
Verdict: go
Objection: foreground dispatch makes a window wait for its slowest build before a refill; accepted because a background notice has been shown to miss its parent and the lead is the only reliable receiver.

## Decisions
1. Only the main session waits on agents, at depth 1: build's lead sends every `Prompt:` of the window to exo:build-task itself in one foreground message and routes each return through `land-task.mjs`, `land-slot.mjs` and `next-task.mjs`; the task-runner layer (agent file, contract row, model kind, references, agent-tier fixtures) is deleted with no shim. Foreground beats background dispatch because it needs no completion notice and works the same in a `-p` run session; the cost is that a refill waits for the window's slowest build. (user decided)
2. `harnesses/coordination-contract.json` is the one place that sets `mayDispatch` and `wait`; exo:orchestrator dispatches only when it sends every worker before it returns and never ends a turn to wait, else it returns its dispatch plan to the lead; a check fails agent or skill prose that tells a subagent to end its turn and wait for a child. (user decided)
3. Until Decision 1 lands, the lead's session rules carry a stall guard: a completion notice for an agent the lead did not spawn, or a spawned agent idle after it reported waiting, makes the lead resume that agent's parent with SendMessage at once. (user decided)
4. `skills/build/scripts/wait-report.mjs` and every caller and prose line that runs it are deleted with no shim (`next-task-window.mjs` `Wait:` lines, `agents/orchestrator.md:21`, the `wait-report` rows of `harnesses/coordination-contract.json`, `sessionWait`, the sleep deny text in `lib/speed-rules.mjs`, `CONTRIBUTING.md:281` and the sleep-step line `CONTRIBUTING.md:230`). (user decided)
5. Every remaining wait is one `wait` kind row in `lib/loop-kinds.json` (the row exists from part 1 with a round cap and gains a wall cap), run through one poll helper in `lib/loop-budget.mjs`; the loop-kinds check (`verify/checks/loop-kinds.mjs`) also fails a script that polls a file or process in a sleep or interval loop outside `lib/loop-budget.mjs`, and loaded prose that tells an agent to poll or rerun a wait. (user decided)
6. `worktreePath(name)` in `lib/checkout.mjs` returns `<main checkout>/.claude/worktrees/<name>`, rooted at the git common dir's checkout, so a slot of a run worktree is the flat sibling `.claude/worktrees/<run>-task-<n>`; `lib/workspace.mjs:87`, `skills/build/scripts/open-slots.mjs:14`, `skills/build/scripts/run-checkout.mjs:33` and `skills/build/scripts/setup.mjs:160` call it and lose their own path code. (user decided)
7. `createWorktree` writes `.claude/worktrees/` to the repo's `.git/info/exclude` when no ignore rule covers it, so a user project gets no tracked-file edit. (user decided)
8. One predicate in `lib/checkout.mjs` for a path inside a worktree folder replaces the hard-coded `.worktrees` in `skills/build/scripts/regions.mjs:8`, `lib/covering-tests.mjs:4`, `lib/edit-impact.mjs:13` and `skills/edit-skills/scripts/rename-skill.mjs:15`, adds the missing skip in regions.mjs and rename-skill.mjs, and matches both `.claude/worktrees` and the legacy `.worktrees`. (user decided)
9. A check in `npm run check` fails a `git worktree add` call or a worktree path literal in a script or loaded prose outside `lib/checkout.mjs`. (user decided)
10. `.claude/CLAUDE.md:7`, `.claude/landing.md:15`, `lib/guard-rules.mjs:139`, `skills/build/references/wave-worktrees.md` and the tests that assert the old shapes move to `.claude/worktrees/`. (user decided)
11. Land per the repo workflow: worktree, squash to main, no push. (user decided)
