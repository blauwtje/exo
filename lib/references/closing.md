# Closing rule

- The final message follows the `## Report rule` below and asks no question back.
- When you made a choice for the user, add one line with its cost if wrong.
- When a request reads two ways, name the rival reading.
- Question ends turn only when choice is user's and routes differ; read the question reference first, ask nothing else, run nothing before answer.

## Report rule

- Report when all work is done, as `output-styles/adhd.md` sets under While working.
- The report holds what happened, whether it worked, and what the user must do now.
- What the user must do now → the last line only, as `output-styles/adhd.md` Show sets.
- Hashes, counts, paths and status words go in the file the work wrote; name that file in one line.
