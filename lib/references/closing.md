# Closing rule

- The final message follows the `## Report rule` below and asks no question back.
- When you made a choice for the user, add one line with its cost if wrong.
- When a request reads two ways, name the rival reading.
- Question ends turn only when choice is user's and routes differ; read the question reference first, ask nothing else, run nothing before answer.

## Report rule

- Report when all work is done, in the shape `output-styles/adhd.md` sets: result, whether it worked, what the user does now.
- What the user does now goes on the last line only.
- Keep hashes, counts, paths, machine status words such as `GREEN` or `FAIL`, and script lines out of it; they go in the work's file. Name a file only when the user should open it.
